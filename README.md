# 내 가계부: 설치와 단축어 연결 안내

토스나 카드사·은행 앱에서 결제 알림이 오면 아이폰 단축어가 가계부를 바로 열고, 사용처를 보고 추천 항목을 미리 골라 둡니다.
추천이 맞으면 **저장**, 틀리면 **세부항목 한 번**만 누르면 기록이 끝납니다.

```
결제 → 앱 알림 도착(1~5초) → 자동화가 즉시 실행 → 사파리에서 입력창 열림(1~2초) → 탭 1번 → 끝
```

목표로 잡은 15초 안에 넉넉히 끝나는 흐름입니다. 같은 사용처를 한 번 분류해 두면 다음부터는 추천이 맞아서 대부분 **저장** 한 번으로 끝납니다.

---

## 1단계: 앱 주소

앱은 GitHub Pages에 올라가 있습니다.

**https://hhggyy7713-stack.github.io/gagyebu/**

앱을 고친 뒤 다시 올릴 때는 이 폴더에서 아래 명령을 실행하면 1~2분 뒤 반영됩니다.

```bash
git add -A && git commit -m "업데이트" && git push
```

> 올라가는 건 앱 화면(코드)뿐입니다. 결제 기록은 서버로 가지 않고 **내 아이폰 사파리 안에만** 저장됩니다.

## 2단계: 토스·카드사·은행 앱 알림 자동화 (메인)

1. **단축어 앱 → 자동화 → ＋ → 앱 알림**을 고르고, 앱에 **토스**와 쓰는 카드사·은행 앱을 넣습니다.
2. 조건: **제목, 부제, 메시지** 중 하나에 `결제`가 들어 있을 때 → **즉시 실행**.
3. 동작 4개를 넣습니다.
   - **텍스트**: 단축어 입력의 `제목`, `부제`, `메시지`를 한 줄씩 (항목을 고를 수 없으면 `단축어 입력`만)
   - **URL 인코딩**: 입력은 위 텍스트
   - **텍스트**: `https://hhggyy7713-stack.github.io/gagyebu/#add=` 바로 뒤에 `URL 인코딩된 텍스트` 변수
   - **URL 열기**: 입력은 위 텍스트
4. 앱 설정 탭의 **결제 알림 테스트**에 실제로 받은 알림 내용을 붙여 넣으면, 금액·사용처를 제대로 읽는지 미리 볼 수 있습니다.

앱이 알아서 걸러 주는 것:

- 결제 예정, 결제일·청구 안내, 결제 실패, 광고 알림은 기록하지 않고 건너뜁니다.
- 토스와 카드사 앱이 같은 결제를 둘 다 알려 와도, 5분 안에 금액과 사용처가 같으면 한 번만 기록합니다.

읽을 수 있는 형식 예:
`배달의민족에서 12,500원 결제했어요`, `12,500원 결제 | 배달의민족`, `[KB국민카드] 12,500원 승인 일시불 배달의민족`, `가맹점: GS25 역삼점 / 결제금액 15,000원`

### 카드 결제 문자(SMS)를 쓰는 경우

**자동화 → ＋ → 메시지**, 메시지 내용에 `승인` → **즉시 실행** → **URL 인코딩**(입력: 단축어 입력) → **텍스트**(위 주소 + 인코딩된 텍스트) → **URL 열기**

## 3단계 (선택): 잠금 상태에서도 놓치지 않기

아이폰이 잠겨 있으면 사파리를 열 수 없어서 기록이 빠질 수 있습니다. 알림 내용을 파일에 먼저 쌓아 두면 이 문제가 해결됩니다.

1. 2단계 자동화 **맨 앞**에 **텍스트 파일에 추가** 동작을 넣습니다.
   - 파일 경로: `Shortcuts/가계부대기.txt`
   - 내용: `단축어 입력`, 줄바꿈, `@@`
2. 새 단축어 **가계부**를 만듭니다.
   - **파일 가져오기**: `Shortcuts/가계부대기.txt` (찾지 못하면 오류 표시 끄기)
   - **URL 인코딩** → **텍스트** `https://hhggyy7713-stack.github.io/gagyebu/#q=` + 인코딩된 텍스트 → **URL 열기**
   - **텍스트**(공백 한 칸) → **파일 저장**: 같은 경로, 덮어쓰기 켜기
3. 이 **가계부** 단축어를 홈 화면에 추가해 앱 아이콘처럼 씁니다. 열 때마다 밀린 결제가 한 번에 들어오고, 이미 들어온 문자는 중복 없이 걸러집니다.

## 애플페이(지갑) 결제도 받기

**자동화 → ＋ → 지갑** → 카드 선택 → 즉시 실행 →
**텍스트** `애플페이|[금액]|[가맹점]|[카드 또는 패스]` → **URL 인코딩** → `…#add=` + 결과 → **URL 열기**

## 꼭 알아 둘 것

- **홈 화면에 추가할 때 ‘웹 앱으로 열기’를 끄세요.** 웹 앱으로 열면 사파리와 저장 공간이 따로 생겨서, 단축어로 들어온 기록이 보이지 않습니다. 3단계의 **가계부** 단축어를 홈 화면에 두는 방법을 가장 추천합니다.
- 사파리 방문 기록·웹사이트 데이터를 지우면 기록도 지워집니다. **설정 → 백업 파일 저장**으로 가끔 iCloud Drive에 저장하세요. CSV로 내보내면 엑셀이나 넘버스에서 열 수 있습니다.
- 사파리에서 **비공개 탭**으로 열면 저장되지 않습니다.

## 다른 가계부 앱에서 가져온 아이디어

이미 넣은 것:

- **지난달 이맘때와 비교** (토스): 단순히 지난달 전체가 아니라 같은 날짜까지의 누적과 비교합니다.
- **하루 쓸 수 있는 돈** (편한가계부, YNAB): 남은 예산을 남은 날수로 나눕니다.
- **정기결제 자동 감지** (뱅크샐러드, 토스): 2개월 이상 비슷한 금액으로 결제된 곳을 구독 후보로 보여 줍니다.
- **한 달 시작일 변경** (편한가계부, 머니매니저): 월급날 기준으로 한 달을 나눌 수 있습니다.
- **무지출 달력** (똑똑가계부, 무지출 챌린지류)
- **사용처 학습** (뱅크샐러드): 한 번 고른 분류를 기억해 다음부터 자동으로 고릅니다.
- **승인취소 자동 상계, 할부 표시, 결제수단별 집계** (머니매니저)

앞으로 넣으면 좋은 것:

1. **할부를 월별로 나눠 잡기** (머니매니저): 지금은 결제한 달에 전액이 잡힙니다. 카드 청구 기준으로 보고 싶다면 필요합니다.
2. **잠금화면·홈 위젯** (토스, 뱅크샐러드): Scriptable 앱으로 이번 달 지출과 예산 잔액을 위젯에 띄울 수 있습니다.
3. **예산 초과 알림**: 카테고리 예산의 80%를 넘으면 단축어 알림을 띄우는 방식으로 붙일 수 있습니다.
4. **여러 기기 동기화** (뱅크샐러드, 네이버 가계부): 지금은 아이폰 한 대 전용입니다. 아이패드나 맥에서도 보려면 구글 시트 같은 저장소를 붙여야 합니다.
5. **영수증 사진 첨부, 태그** (편한가계부, Money Lover): 여행이나 경조사처럼 카테고리를 가로지르는 묶음에 유용합니다.
6. **연말정산 미리보기** (뱅크샐러드): 체크·신용카드 사용액 비율을 결제수단별 집계에서 바로 계산할 수 있습니다.
