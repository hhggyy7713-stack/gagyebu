# 내 가계부: 설치와 단축어 연결 안내

토스나 카드사·은행 앱에서 결제 알림이 오면 아이폰 단축어가 가계부를 바로 열고, 사용처를 보고 추천 항목을 미리 골라 둡니다.
추천이 맞으면 **저장**, 틀리면 **세부항목 한 번**만 누르면 기록이 끝납니다. 잠겨 있어서 놓친 결제는 파일에 쌓였다가 나중에 한 번에 들어옵니다.

```
결제 → 앱 알림 도착(1~5초) → 자동화가 즉시 실행 → 사파리에서 입력창 열림(1~2초) → 탭 1번 → 끝
```

목표로 잡은 15초 안에 넉넉히 끝나는 흐름입니다. 같은 사용처를 한 번 분류해 두면 다음부터는 추천이 맞아서 대부분 **저장** 한 번으로 끝납니다.

---

## 1단계: 앱 주소

앱은 GitHub Pages에 올라가 있습니다.

**https://hhggyy7713-stack.github.io/gagyebu/**

앱을 고친 뒤 다시 올릴 때는 이 폴더에서 아래 명령을 실행하면 1~2분 뒤 반영됩니다.

```bash
git add -A && git commit -m "업데이트" && git push
```

> 올라가는 건 앱 화면(코드)뿐입니다. 결제 기록은 서버로 가지 않고 **내 아이폰 사파리 안에만** 저장됩니다.

## 2단계: 단축어 '가계부 기록' 만들기

결제 알림이 올 때마다 실행되는 단축어입니다. 동작을 이 순서로 넣습니다.

1. **날짜 형식 지정**: `현재 날짜`, 형식은 사용자 지정 `yyyy-MM-dd HH:mm`
2. **텍스트**: 한 줄씩 `형식이 지정된 날짜`, `제목`, `부제`, `메시지`. 알림 항목을 고를 수 없으면 날짜 다음 줄에 `단축어 입력`만 넣습니다.
3. **텍스트 파일에 추가**: 파일 `Shortcuts/가계부대기.txt`, 내용은 2번 텍스트, 다음 줄에 `@@`
4. **알림 보기**: "이 지출을 가계부에 기록할까요?", 줄바꿈, 2번 텍스트. **취소 버튼 보기**를 켭니다.
5. **URL 인코딩**: 입력은 2번 텍스트
6. **텍스트**: `https://hhggyy7713-stack.github.io/gagyebu/#add=` 바로 뒤에 `URL 인코딩된 텍스트`
7. **URL 열기**

3번에서 결제를 파일에 먼저 적어 두기 때문에, 휴대폰이 잠겨 있거나 확인을 못 눌러도 결제가 사라지지 않습니다. 4단계의 '가계부' 아이콘을 열 때 들어옵니다.

## 3단계: 자동화 만들기

1. **단축어 앱 → 자동화 → ＋ → 앱 알림**
2. 앱: **토스**와 쓰는 카드사·은행 앱
3. 조건: 제목, 부제, 메시지에 `결제` → **즉시 실행**
4. 다음 → 새로운 빈 자동화 → **단축어 실행**: `가계부 기록`, 입력은 `단축어 입력`

어떤 앱은 '결제' 대신 '승인'이나 '사용'이라고만 알려 줍니다. 그런 앱이 있으면 조건만 `승인`으로 바꾼 자동화를 하나 더 만듭니다. 결제 예정, 결제일 안내, 결제 실패, 광고 알림은 앱이 알아서 건너뛰고, 같은 결제가 여러 번 들어와도 한 번만 기록됩니다.

카드 결제 **문자(SMS)**를 받는다면 **자동화 → ＋ → 메시지**, 내용에 `승인` → 즉시 실행 → `가계부 기록` 실행으로 같은 단축어를 씁니다.

## 4단계: 홈 화면 '가계부' 아이콘 (밀린 결제 한 번에 넣기)

1. 새 단축어 **가계부**를 만듭니다.
   - **파일 가져오기**: `Shortcuts/가계부대기.txt` (찾지 못하면 오류 표시 끄기)
   - **URL 인코딩** → **텍스트** `https://hhggyy7713-stack.github.io/gagyebu/#q=` + 인코딩된 텍스트 → **URL 열기**
   - **텍스트**(공백 한 칸) → **파일 저장**: 같은 경로, 덮어쓰기 켜기
2. 이 단축어를 홈 화면에 추가해 앱 아이콘처럼 씁니다.
3. 열면 놓친 결제가 **결제한 시각 그대로** 들어옵니다. 이미 기록한 건 자동으로 빠집니다.
4. 여러 건이면 입력창 위의 **추천대로 모두 저장**을 누릅니다. 추천이 없는 것만 하나씩 물어봅니다.
5. 확인 창에서 **취소**했던 결제도 여기서 한 번 더 보입니다. 기록하지 않을 거면 **삭제**를 누르면 다시 나오지 않습니다.

## 자동화가 가끔 실행되지 않을 때

알림 자동화는 iOS가 알림을 실제로 화면에 보여 줄 때만 실행됩니다. 아래를 확인하세요.

- **설정 → 알림 → 예약된 요약**에 토스나 카드사 앱이 들어 있으면 뺍니다. 요약으로 묶인 알림은 바로 전달되지 않습니다.
- **집중 모드**(수면, 업무 등)에서 그 앱의 알림이 꺼져 있으면, 집중 모드의 허용 앱에 추가합니다.
- 토스와 카드사 앱 알림 설정에서 **잠금 화면** 표시가 켜져 있는지 봅니다.
- **설정 → 단축어 → 알림**을 허용합니다. 확인 창을 띄우려면 필요합니다.
- 저전력 모드에서는 늦게 실행될 수 있습니다.

그래도 빠지는 결제가 있으니 하루에 한 번 홈 화면의 **가계부** 아이콘을 열어 주세요. 단축어가 실행된 결제는 모두 파일에 남아 있어서 여기서 채워집니다. 자동화가 아예 실행되지 않은 결제는 파일에도 없으니 **＋**로 직접 넣어야 합니다.

## 애플페이(지갑) 결제도 받기

**자동화 → ＋ → 지갑** → 카드 선택 → 즉시 실행 →
**텍스트** `애플페이|[금액]|[가맹점]|[카드 또는 패스]` → **URL 인코딩** → `…#add=` + 결과 → **URL 열기**

## 꼭 알아 둘 것

- **홈 화면에 추가할 때 ‘웹 앱으로 열기’를 끄세요.** 웹 앱으로 열면 사파리와 저장 공간이 따로 생겨서, 단축어로 들어온 기록이 보이지 않습니다. 4단계의 **가계부** 단축어를 홈 화면에 두는 방법을 가장 추천합니다.
- 사파리 방문 기록·웹사이트 데이터를 지우면 기록도 지워집니다. **설정 → 백업 파일 저장**으로 가끔 iCloud Drive에 저장하세요. CSV로 내보내면 엑셀이나 넘버스에서 열 수 있습니다.
- 사파리에서 **비공개 탭**으로 열면 저장되지 않습니다.

## 다른 가계부 앱에서 가져온 아이디어

이미 넣은 것:

- **지난달 이맘때와 비교** (토스): 단순히 지난달 전체가 아니라 같은 날짜까지의 누적과 비교합니다.
- **하루 쓸 수 있는 돈** (편한가계부, YNAB): 남은 예산을 남은 날수로 나눕니다.
- **정기결제 자동 감지** (뱅크샐러드, 토스): 2개월 이상 비슷한 금액으로 결제된 곳을 구독 후보로 보여 줍니다.
- **한 달 시작일 변경** (편한가계부, 머니매니저): 월급날 기준으로 한 달을 나눌 수 있습니다.
- **무지출 달력** (똑똑가계부, 무지출 챌린지류)
- **사용처 학습** (뱅크샐러드): 한 번 고른 분류를 기억해 다음부터 자동으로 고릅니다.
- **승인취소 자동 상계, 할부 표시, 결제수단별 집계** (머니매니저)

앞으로 넣으면 좋은 것:

1. **할부를 월별로 나눠 잡기** (머니매니저): 지금은 결제한 달에 전액이 잡힙니다. 카드 청구 기준으로 보고 싶다면 필요합니다.
2. **잠금화면·홈 위젯** (토스, 뱅크샐러드): Scriptable 앱으로 이번 달 지출과 예산 잔액을 위젯에 띄울 수 있습니다.
3. **예산 초과 알림**: 카테고리 예산의 80%를 넘으면 단축어 알림을 띄우는 방식으로 붙일 수 있습니다.
4. **여러 기기 동기화** (뱅크샐러드, 네이버 가계부): 지금은 아이폰 한 대 전용입니다. 아이패드나 맥에서도 보려면 구글 시트 같은 저장소를 붙여야 합니다.
5. **영수증 사진 첨부, 태그** (편한가계부, Money Lover): 여행이나 경조사처럼 카테고리를 가로지르는 묶음에 유용합니다.
6. **연말정산 미리보기** (뱅크샐러드): 체크·신용카드 사용액 비율을 결제수단별 집계에서 바로 계산할 수 있습니다.
